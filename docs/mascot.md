# 3D-маскот: заметки по прототипу

Прототип `reference/Первый экран 3D.html` (в git не попадает) — справка по ригу и анимациям, не код для копирования.
Там модели вшиты в HTML base64-строками (8,8 МБ), three@0.160 тянется с CDN, тени и PMREM на каждом устройстве — так не делаем.

## Модели (`public/models/`)

| Файл | Что | Размер |
|---|---|---|
| `artem.glb` | маскот, skinned mesh, 17 костей, без анимаций (T-поза) | ~1,2 МБ |
| `tool-*.glb` | 8 логотипов инструментов: figma, claude, tilda, gpt, claude_code, git, yougile, flow | 95–250 КБ |

Сжаты `npm run optimize:models` (gltf-transform): `EXT_meshopt_compression` + `KHR_mesh_quantization`, текстуры WebP
(маскот 2048², логотипы 512²; в оригинале 4096² ≈ 90 МБ VRAM на текстуру). Нужен `MeshoptDecoder` в `GLTFLoader`.

## Риг

Кости, которые двигает прототип (имена через `THREE.PropertyBinding.sanitizeNodeName`):
`head`, `spine`, `upperarm.L/R`, `forearm.L/R`, `hand.L/R`.

- Модель в T-позе → в покое руки опускаются кодом: `upperarm.L.rotation.z = -1.2`, `upperarm.R.rotation.z = +1.2`, предплечья ∓0.12.
- Нормализация: масштаб так, чтобы рост ≈ 0.98, ноги на y=0, центр по X/Z. Голова ≈ 0.66·H.
- Иерархия: `rig` (поворот к курсору) → `hopper` (прыжок/дыхание) → модель. Для хит-теста — невидимый цилиндр-прокси, а не raycast по skinned mesh.

## Анимации (процедурные, в цикле рендера)

- **Взгляд за курсором**: yaw = mouse.x·0.55, pitch = −mouse.y·0.14, сглаживание `dt·4`. Тело `rig` поворачивается на 0.35·yaw, `spine` 0.15·yaw, `head` 0.95·yaw и 1.4·pitch. Без курсора 6 с — медленное «осматривание» синусами.
- **Дыхание**: scale.y ×(1 + sin(2t)·0.006), руки покачиваются sin(1.6t)·0.04.
- **Кивок** (0.7 с), **помахать** левой рукой (2 с), **cheer** — обе руки вверх (1.8 с), **прыжок** со squash&stretch (0.6 с). Огибающая `sin(min(1, 3.5u, 3.5(1−u))·π/2)`.
- **Логотипы**: наклонённая орбита вокруг кудрей (R = 0.6·H, на мобильном 0.5·H, высота 0.8·H), размер 0.17·H, покачивание и вращение со сдвигом фаз; при наведении орбита тормозит, логотип увеличивается и показывает подпись; клик — «пинок» с оборотом.
- **Скролл**: секция 190vh со sticky-сценой; прогресс скролла меняет кадр камеры с «голова+торс» до «в полный рост», ускоряет орбиту, гасит заголовок; на 92 % — cheer + прыжок + реплика «Вот и ноги!».
- **Реплики** в пузыре у головы по клику по маскоту.

Сцена: `PerspectiveCamera(fov 28)`, ACES tone mapping, RoomEnvironment, hemi + key + rim свет, мягкая тень-блоб текстурой вместо shadow map.

## Что делать иначе (см. правила в CLAUDE.md)

- Сначала статичный AVIF-кадр маскота (через `astro:assets`), 3D — остров `client:idle`, подменяет картинку после загрузки.
- Один `WebGLRenderer` на сайт; `IntersectionObserver` останавливает цикл вне viewport; `pixelRatio ≤ 2`.
- На touch и при `prefers-reduced-motion` — без слежения за курсором (и без «осматривания»), без автодвижения орбиты.
- Модели грузить из `public/models/` через `GLTFLoader` + `MeshoptDecoder`, three — из npm, не с CDN.
- Цвета UI вокруг сцены — из токенов (в прототипе другая палитра: оранжевый акцент, тёплый фон).
